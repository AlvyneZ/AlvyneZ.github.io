Technical Skills

Embedded Systems & Firmware

Protocols & Hardware Bring-Up

Inter-system communication protocols (UART, RS485, RS422, SPI, I2C, USB), RF telemetry/telecommand links, custom PCB validation, and sensor integrations.

Software Engineering

Strong proficiency in C & C++, Python, Dart, and JavaScript, building performant test benches, control tools, and automated profiling scripts.

Multiplatform App Development

Engineering responsive mobile, desktop, and web applications with Flutter for real-time hardware telemetry display, instrumentation, and profiling.

Embedded Linux

Experience with Embedded Linux on Raspberry Pi, Toradex, and Xilinx FPGAs. Worked on building device trees for custom boards and writing custom Linux kernel drivers.

SDRs, Verilog & FPGAs

Experience with custom SDR board bring-up, multi-stage bootloader configuration (FSBL/U-Boot), and implementing digital RF baseband processing pipelines using Verilog on AMD Xilinx FPGAs.

Debugging & Troubleshooting

Strong problem-solving skills with experience in systematic hardware-software diagnostics using digital oscilloscopes, logic analyzers, JTAG/SWD debuggers, GDB, and profiling tools.

Backend Development & Database Design

Backend engineering with Node.js/Express and REST API design, relational database design with MySQL, and cloud datastores like Firebase NoSQL.
